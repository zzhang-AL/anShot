# 真实网页抓帧回归样本

这两张 PNG 来自本项目自己的 `CaptureDiagnostics+ScrollshotLive.swift` 测试页面，
不含用户聊天、第三方应用正文或第三方应用素材。采集日期为 2026-10-27。

* macOS 原生抓帧，Retina 2x；中文、英文、数字混排。
* 原始窗口具有固定标题栏、侧栏和底部输入栏。
* 样本按识别出的正文矩形裁剪：`x=240, y=80, width=1280, height=880`。
* `previous.png` 与 `next.png` 对应相差 200 逻辑点的两个视口，
  正文在下一帧上移 **400 物理像素**；互换两帧的位移为 **-400**。
* 右侧滚动条仍存在，不能把它的移动当成正文位移证据。

`ScrollshotCapturedFrameTests` 验证双向位移及会话覆盖区间。
确定性合成帧测试另行验证明细、预览和导出的逐像素一致性。
